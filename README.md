# hplc calendar

Upload index.html and .nojekyll to your GitHub repository, then enable GitHub Pages for that branch/root folder.

This is the live shared calendar, not the sample prototype. The frontend connects to the hosted calendar database at https://together-hangouts-k7m4.basiccamel256.chatgpt.site. Keep that backend published: GitHub Pages alone cannot store shared edits.

Everyone using this site shares one calendar. Names are entered on first visit; the browser remembers a private editing key. Clearing browser storage or changing browsers creates a new identity. Names are not passwords and duplicate names do not recover old entries.

Live map: OpenStreetMap / Leaflet. Weather: Open-Meteo, up to 16 forecast days; dates outside the forecast show unavailable. Activity suggestions use weather rules and your group's ideas.

Map pins, availability, ideas, events and colours are stored on the server and refresh approximately every 8 seconds while the page is visible. No example people or entries are seeded.

The link is public: everyone who has it can view the group calendar and join.
